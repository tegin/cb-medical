=========================
Account Portal Commission
=========================

This module allow users as doctors see their commissions in the portal. From one sice, he can a panel resuem with the total amounts of their commissions grouped by commission state. By the other hand, he can search specific commissions info from encounters code.

Usage
============

#. Externals users only must have permission to see their commissions in the portal. In this way, a permission group (Account Portal Restricted Group) has been created to manage it. Users that want to see their commissions in the portal must be added to this group first and ensure for security that he dowsn't below to a relevant group as administrator, etc.
#. Once the user has the permission, ensure that he has commissions related to him.
#. User must access to the portal and click on the "Commissions" menu item. A panel will be desplayed. Also a button is available to search specific commissions by encounter code.
